UC-Central API Documentation

This is a static HTML version of the documentation for AI tools and non-JS environments.

Authentication

Authenticate using JWT Token or API Key (x-api-key header).

Endpoints

  • POST /auth/login - Login
  • POST /auth/register - Register

Data Models

User Schema

{
    "studentId": "String",
    "email": "String",
    "firstName": "String",
    "lastName": "String",
    "role": "String",
    "apiKey": "String"
}

Event Schema

{
    "title": "String",
    "date": "String",
    "location": "String",
    "attendees": "[User]"
}

Merch Schema

{
    "name": "String",
    "price": "Number",
    "stock": "Number",
    "variants": "[{ size, color, stock }]"
}

Order Schema

{
    "user": "User",
    "items": "[{ merch, quantity }]",
    "totalPrice": "Number",
    "status": "String"
}

Resources

  • GET /users - Get all users
  • GET /auth/me - Get profile
  • GET /events - Get events
  • POST /events - Create event
  • GET /merch - Get merchandise
  • GET /orders - Get orders
  • POST /orders - Create order
  • GET /announcements - Get announcements
